☁️ الربط السحابي التلقائي بين الموبايل والكمبيوتر

خطوات تفعيل المزامنة المجانية في دقيقتين (مرة واحدة فقط):

  1. ادخل بحساب جوجل على موقع console.firebase.google.com واضغط Create a project (أو Add project) واكتب أي اسم للمشروع.
  2. من القائمة الجانبية اختر Build ثم Realtime Database واضغط Create Database.
  3. اختر وضع Start in test mode ثم اضغط Enable.
  4. انسخ الرابط الظاهر أعلى الجدول (ينتهي بـ firebaseio.com) والصقه في الخانة بالأعلى، واكتب نفس رمز الحماية على الموبايل والكمبيوتر.
  5. لتشغيل البرنامج على الموبايل والكمبيوتر معاً: ارفع هذا الملف مجاناً على app.netlify.com/drop لتحصل على رابط إنترنت يفتح من أي جهاز فوراً!
